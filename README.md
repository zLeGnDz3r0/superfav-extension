## ✨ ¿Qué es SuperFav?

**SuperFav** es una extensión gratuita para **Chrome** (y otros navegadores Chromium) que te permite marcar streamers de **Twitch** y **Kick** con un **botón de diamante** (púrpura / verde flúor) y enterarte al instante cuando entran en directo.

Olvídate de revisar manualmente cada canal: el **badge rojo**, el **popup** con la lista de directos y las **notificaciones de escritorio** hacen el trabajo por ti.

> 🔒 **Privado por diseño:** tus favoritos se guardan en *tu* navegador. No hay cuenta, no hay registro, no compartimos tu lista con nadie.

---

## 🚀 Funcionalidades

| | Feature | Descripción |
|---|---------|-------------|
| 💎 | **Un clic para marcar** | Diamante en cualquier canal de Twitch o Kick. |
| 🟣🟢 | **Plataforma visible** | Chip Twitch / Kick en el popup y en Mis SuperFavs. |
| 🔴 | **Badge de directos** | Contador rojo. Poll cada **3 minutos**; sync al abrir el popup. |
| 🖥️ | **Avisos en el escritorio** | Toast cuando un favorito empieza a emitir. |
| 📋 | **Cambio de título** | Detecta cambios cada **30 segundos**. |
| ⚙️ | **Avisos por canal** | Engranaje → Directo / Título por SuperFav + sonido. |
| 🌍 | **Multi-idioma** | ES, EN, CA, FR, IT, DE, TR, HI, ZH, JA. |
| 🔐 | **Local y seguro** | Favoritos en `chrome.storage`. |

## 🛠️ Instalación

### Opción A — Chrome Web Store (recomendada)

1. Abre [SuperFav en Chrome Web Store](https://chromewebstore.google.com/detail/kgnhcepaobaiklnggoebppljgobkpckc)
2. Pulsa **Añadir a Chrome**

### Opción B — Desde el código fuente

```bash
git clone https://github.com/zLeGnDz3r0/superfav-extension.git
cd superfav-extension
npm install
npm run build
```

Carga `dist/` en `chrome://extensions` (modo desarrollador).
